4. Open Questions

Open Questions
  • Blocking vs scoped data (widget_access.data_scope): It is undecided whether a data_scope = 'self' policy means the widget is entirely hidden for non-managers, or whether it is shown with a scoped view (own-row only). This decision affects how the access engine interprets widget_access.data_scope and what the routing layer returns — a denial or a filtered result set. Pending product decision before LLD 08 is finalised.
  • First ERP target: The erp_connectors table has columns for multiple ERP systems, but which connector is implemented first determines which erp_type values are populated in the early schema and which data_sources rows need to exist before the first tenant can onboard. This blocks the LLD 01 connector implementation and should be decided before the ingestion sprint begins.
